# 🤖 Climate Awareness AI Work Space

This directory contains resources, rules, and blueprints that guide AI agents (and human developers) in maintaining, refactoring, or expanding this project.

## 📁 Directory Structure

- **`ai/skills/`** - Permanent reference guides:
  - [`ai_agent_rules.MD`](./skills/ai_agent_rules.MD): Rules, safety boundaries, and workflow guidelines.
  - [`product_specifications.MD`](./skills/product_specifications.MD): Core concept, data math formulas, and design style reference.
  - [`technical_architecture.MD`](./skills/technical_architecture.MD): Technical stack, state architecture, and routing.
  - [`new_section.MD`](./skills/new_section.MD): A step-by-step modular blueprint to add new visualization sections.
- **`ai/handover/`** - Session-specific transition files:
  - [`next_steps.MD`](./handover/next_steps.MD): Logs recent changes and acts as the current active task queue.

## 🧭 How to Start a Session

If you are an AI assistant starting a new session:
1. **Read `ai/skills/ai_agent_rules.MD`** to understand non-negotiable boundaries (such as git hygiene and workflow rules).
2. **Read `ai/skills/product_specifications.MD`** and `ai/skills/technical_architecture.MD` to understand the data, concept, and project layout.
3. **Read `ai/handover/next_steps.MD`** to check the active todo list, recent changes, and current development tasks.
